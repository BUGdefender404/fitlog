# 轻食记 (fitlog)

减脂饮食记录 PWA —— 薄荷健康的精简版。拍照 → GLM-4V 识别食物与份量 → 匹配本地食物库（《中国食物成分表》约 150 种常见食物）→ 确认修正后记入三餐 → 与自动计算的每日减脂目标对比。

## 快速开始

```bash
npm install
npm run build   # 构建前端
npm start       # 启动服务（默认 8899 端口）
```

- 电脑访问：http://localhost:8899
- 手机访问：手机与电脑连同一 Wi-Fi，用启动时打印的局域网地址（如 http://192.168.x.x:8899）
  - 首次启动 Windows 防火墙弹窗请选择「允许访问」

## 配置 (.env)

| 变量 | 说明 |
|---|---|
| ZHIPU_API_KEY | 智谱开放平台 API Key（免费档） |
| ZHIPU_MODEL | 视觉模型，默认 `glm-4v-flash`（官方免费，调用计费 0 元）。备选 `glm-4.6v-flash`（效果更好，长期使用前在控制台「用量明细」确认费用为 0） |
| PORT | 服务端口，默认 8787 |

## 数据

- 全部数据在 `data/fitlog.db`（SQLite），定期备份该文件即可
- 食物库种子在 `foods.json`；AI 识别过且库内没有的食物会自动沉淀为自定义食物，下次识别直接用库内标准值

## 数值口径

- 基础食物：库内标准值（每 100g），数值稳定
- 库外菜品：AI 估算，界面上标「AI估算」徽标
- 识别结果全部可改克数、改名称、删除后再入库

## 开发模式

```bash
npm run dev:server   # 后端 :8787
npm run dev          # 前端 :5173（/api 自动代理到后端）
```

## 路线图

- M1（当前）：三餐记录、拍照识别、目标计算、每日汇总
- M2：体重记录与趋势、常吃食物收藏、周/月统计图表、运动/饮水记录
- M3：PWA 打磨（manifest/离线壳）+ 免费云托管部署（手机 24h 可用）
