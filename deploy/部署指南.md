# 部署指南

轻食记支持三种运行方式，按需选择（可同时用，数据各自独立）。

## 方案 A：GitHub Pages 云端（已部署 ✅ 推荐，手机 24 小时可用）

- 地址：**https://bugdefender404.github.io/fitlog/**
- 数据存在手机浏览器（IndexedDB），不依赖电脑开机
- 拍照识别需在「我的」页粘贴一次智谱 API Key（只存手机本地）
- 首次打开：浏览器菜单 →「添加到主屏幕」→ 之后像 App 一样全屏使用
- 备份：「我的」页可一键导出/导入 JSON 备份文件

## 方案 B：家里电脑服务器（已可运行 ✅ 局域网用）

- 双击项目里的 `启动轻食记.bat`，页面打印局域网地址和二维码
- 手机连同一 Wi-Fi（或给电脑开热点）扫码访问，输入访问口令
- 数据在电脑 `data/fitlog.db`，复制文件即备份
- API Key 在 `.env`，由服务端保管

## 方案 C：云服务器 VPS（以后想自有数据时用）

任意能跑 Docker 的服务器（推荐：Oracle Cloud 永久免费 ARM 实例，或国内轻量云约 ¥40/月）：

```bash
# 在项目目录构建并上传镜像，或直接在服务器上：
docker build -t fitlog .
docker run -d --name fitlog -p 8899:8899 \
  -e ZHIPU_API_KEY=你的key \
  -e ACCESS_PIN=你的口令 \
  -v fitlog-data:/app/data fitlog
```

建议配合 Caddy/Certbot 上 HTTPS 后即可像方案 A 一样安装 PWA。

## 更新部署

```bash
npm run build                                  # 构建前端
cd dist && git add -A && git commit -m deploy && git push -f origin gh-pages && cd ..
git add -A && git commit -m "update" && git push   # 源码备份
```
